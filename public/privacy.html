Privacy Notice for Diagramwise MCP

Last updated: September 13, 2026

This notice describes the data handled by Diagramwise’s MCP integration, a provider-neutral catalog service for architecture components.

What the integration receives

Catalog requests may include a search query, provider or category filter, component identifier, and configuration properties supplied by the MCP client. The public catalog endpoint does not require an account and is not designed to identify individual users.

How data is used

Requests are used to search the supported catalog, return component definitions, and validate component properties. The MCP service does not make LLM calls. Operational logs may contain request identifiers, route, timing, status, and error details so the service can be secured and operated. Authentication tokens are used for authorization and are not returned in tool results.

Storage and service providers

The MCP service may run on AWS Lambda and write operational logs to AWS CloudWatch. The service may read catalog records from Diagramwise’s API. Retention is governed by the configuration of those services and is limited to what is needed to operate, secure, and improve the service.

Your choices

Do not send secrets or personal information in catalog queries or component properties. For privacy questions or a request about data associated with a request, contact support@next-zen.dev.
