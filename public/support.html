Diagramwise MCP Support

Support for the Diagramwise catalog integration

Email support@next-zen.dev with the MCP client, endpoint URL, approximate time, request ID, and a short description of the problem. Please do not include bearer tokens or other secrets.

Available endpoints

  • /chatgpt-mcp — public, read-only catalog tools.
  • /mcp — authenticated MCP tools for compatible clients.
  • /health — service health check.

Common checks

Confirm that the MCP URL uses HTTPS, that a protected connection sends Authorization: Bearer …, and that your client is using the read-only endpoint when it only needs catalog access.
